# neon-kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@sm-steel/neon-kit`, a zero-runtime-dependency TypeScript package that renders contrib-neon's "neon panel" look (frame, brackets, scanlines, beam, boot flicker, glitch tears, HUD title, cursor, embedded Monaspace Neon v1.400 with Cyrillic), gate it on a user-approved local preview, publish it to npm, and migrate contrib-neon onto it as v1.1.0.

**Architecture:**
- Small pure modules that return SVG/CSS strings: `util`, `palette`, `font`, `frame`, `hud`, `effects`.
- A high-level `card(opts, contentSvg)` wraps arbitrary SVG content in the full animated frame.
- The font is subset at build time by a TypeScript script and committed as base64 in `src/font-data.ts`. The published package ships only compiled JS and `.d.ts` files.

**Tech Stack:**
- Node 24.21 via mise; ESM; TypeScript 7 (`tsc` for type-check and emit); Vitest 5; Biome 2.
- Build-time only: `subset-font` 2.9.0 (HarfBuzz) and `wawoff2` 2.0.1.

**Spec:** `docs/specs/2026-10-10-neon-kit-design.md` in this repo. Read it alongside this plan.

**Deviations from the spec, decided during planning with evidence from spikes:**
1. **Font source.** It is the **variable** TrueType `Monaspace Neon Var.woff2`, pinned to wght 400/700 via HarfBuzz instancing, instead of the static CFF files. The static files keep `MonaspaceNeon-Regular` inside the CFF table, which the `name`-table rewrite can't reach and which would violate the OFL Reserved Font Name clause. Instanced TrueType has no CFF table. It is also smaller: 14.5 KB WOFF2 per weight for the `text` set.
2. **Name records.** The source has no copyright in name ID 0. Its copyright and Reserved Font Name text is in **ID 7**, and the license is in ID 13. HarfBuzz keeps only IDs 1–6. The build rebuilds the whole name table and copies ID 7 → ID 0 and ID 13 → ID 13.
3. **Emit.** `tsc` emits both the JS and the `.d.ts` files (`rewriteRelativeImportExtensions`). esbuild isn't needed for a library.
4. **Ids.** All kit-generated SVG ids and classes are prefixed `nk-`, so they can't collide with consumer content.
5. **Font option.** `card()` gets an optional `font` option, because widgets need the bold `text` variant. The spec left this open.

## Global Constraints

- Node `>=22.18` in `engines`, Node `24.21.0` pinned in `mise.toml`. Source imports use explicit `.ts` extensions.
- **No runtime dependencies** in `package.json` `dependencies`. `subset-font` and `wawoff2` are devDependencies only.
- Font source: `https://raw.githubusercontent.com/githubnext/monaspace/v1.400/fonts/Web%20Fonts/Variable%20Web%20Fonts/Monaspace%20Neon/Monaspace%20Neon%20Var.woff2`, with SHA-256 `6569968f448ae856ab5b57dff1f13b109b220ca8e3f664169e135fcb5c4f0721`.
- Embedded font family name: `ContribNeon Mono`. The name IDs 1–6 must not contain "Monaspace".
- Frame: square panel at `x=y=.5` with a 1px `border` stroke. Brackets sit 4px inside the edge with 10px arms, a 1.5px stroke, opacity .8 and color `accent`.
- Scanlines: a 3px period with 1px lines. Dark palettes use `#000000` at .28; light palettes use `text` at .05.
- Beam: a 40px-tall gradient band whose middle stop opacity is .09 (dark) or .06 (light), with a 6s period.
- `card()` timings: boot 0.5s once, beam 6s, glitch one tear per 10s, tear duration 0.126s, cursor blink 1.1s.
- HUD text: size 10, letter-spacing 1.2, character width 0.62em, so 7.4px per character. The cursor sits 2px after the text and is 5×9.
- `prefers-reduced-motion: reduce` disables every animation.
- All numbers written into SVG/CSS are rounded to ≤ 3 decimals.
- Git: commit author is the machine default (`sm.steel@hotmail.com`). Do not pass `-c user.email`. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Never loosen Biome rules or add excludes to make findings go away.** Fix the code instead, and ask the user if that seems impossible.
- Line endings are LF (`.gitattributes` already exists).
- **Outward-facing steps need the user's explicit go-ahead at that moment:** creating the GitHub repo, pushing, publishing to npm, tagging contrib-neon. The user does the first npm login + publish and the trusted-publisher setup themselves; no npm token is ever created.

## Review Focus

1. **XML-special characters** (`& < > " '`) in `title` or `label`. Expected: escaped, and the SVG stays well-formed. Tested in Task 7.
2. **Consumer content whose ids clash with kit ids** (e.g. a widget using `id="sl"`). Expected: no clash, because every kit id starts with `nk-`. Tested in Task 7.
3. **Very short content** (a one-line card, height 12). Expected: the glitch tear stays inside the content area and never produces a negative or NaN height. Tested in Task 7.
4. **Fractional sizes** from layout engines (e.g. `width: 418.66666666`). Expected: every number in the output has ≤ 3 decimals, with no `e-` notation. Tested in Task 7.
5. **Titles with characters outside the BMP, such as emoji.** Expected: the cursor position counts code points, not UTF-16 units. Tested in Task 5.

```ts
const ESC: Record<string, string> = {
	"<": "&lt;",
	">": "&gt;",
	"&": "&amp;",
	'"': "&quot;",
	"'": "&apos;",
};

/** Escapes text for use in SVG/XML content and attribute values. */
export const esc = (s: string): string => s.replace(/[<>&"']/g, (ch) => ESC[ch] as string);

/** Rounds to at most 3 decimals, so SVG/CSS output stays short and stable. */
export const r3 = (n: number): number => {
	const v = +n.toFixed(3);
	return Object.is(v, -0) ? 0 : v;
};

/** Deterministic PRNG (mulberry32) seeded from a string, returning [0, 1). */
export function seeded(text: string): () => number {
	let h = 1779033703 ^ text.length;
	for (let i = 0; i < text.length; i++) {
		h = Math.imul(h ^ text.charCodeAt(i), 3432918353);
		h = (h << 13) | (h >>> 19);
	}
	let a = h >>> 0;
	return () => {
		a = (a + 0x6d2b79f5) | 0;
		let t = Math.imul(a ^ (a >>> 15), 1 | a);
		t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
		return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
	};
}
```

```ts
// Minimal OpenType (sfnt) helpers for the font build and its tests: read/write the
// table directory, rebuild the `name` table, read `cmap` and advance widths.

export interface Sfnt {
	flavor: number;
	tables: Map<string, Buffer>;
}

export interface NameRecord {
	platform: number;
	encoding: number;
	language: number;
	id: number;
	bytes: Buffer;
}

const pad4 = (b: Buffer): Buffer => {
	const extra = (4 - (b.length % 4)) % 4;
	return extra ? Buffer.concat([b, Buffer.alloc(extra)]) : b;
};

export function checksum(b: Buffer): number {
	const p = pad4(b);
	let sum = 0;
	for (let i = 0; i < p.length; i += 4) sum = (sum + p.readUInt32BE(i)) >>> 0;
	return sum;
}

export function readSfnt(buf: Buffer): Sfnt {
	const tables = new Map<string, Buffer>();
	const count = buf.readUInt16BE(4);
	for (let i = 0; i < count; i++) {
		const o = 12 + i * 16;
		const offset = buf.readUInt32BE(o + 8);
		tables.set(buf.toString("latin1", o, o + 4), buf.subarray(offset, offset + buf.readUInt32BE(o + 12)));
	}
	return { flavor: buf.readUInt32BE(0), tables };
}

export function writeSfnt({ flavor, tables }: Sfnt): Buffer {
	const tags = [...tables.keys()].sort();
	const n = tags.length;
	const entrySelector = Math.floor(Math.log2(n));
	const searchRange = 2 ** entrySelector * 16;
	const dir = Buffer.alloc(12 + n * 16);
	dir.writeUInt32BE(flavor, 0);
	dir.writeUInt16BE(n, 4);
	dir.writeUInt16BE(searchRange, 6);
	dir.writeUInt16BE(entrySelector, 8);
	dir.writeUInt16BE(n * 16 - searchRange, 10);

	const bodies: Buffer[] = [];
	let offset = dir.length;
	let headOffset = -1;
	tags.forEach((tag, i) => {
		let data = tables.get(tag) as Buffer;
		if (tag === "head") {
			data = Buffer.from(data);
			data.writeUInt32BE(0, 8); // checkSumAdjustment is computed last
			headOffset = offset;
		}
		const o = 12 + i * 16;
		dir.write(tag, o, "latin1");
		dir.writeUInt32BE(checksum(data), o + 4);
		dir.writeUInt32BE(offset, o + 8);
		dir.writeUInt32BE(data.length, o + 12);
		const padded = pad4(data);
		bodies.push(padded);
		offset += padded.length;
	});

	const out = Buffer.concat([dir, ...bodies]);
	if (headOffset >= 0) out.writeUInt32BE((0xb1b0afba - checksum(out)) >>> 0, headOffset + 8);
	return out;
}

export function readNames(table: Buffer): NameRecord[] {
	const count = table.readUInt16BE(2);
	const strings = table.readUInt16BE(4);
	const records: NameRecord[] = [];
	for (let i = 0; i < count; i++) {
		const o = 6 + i * 12;
		const len = table.readUInt16BE(o + 8);
		const off = strings + table.readUInt16BE(o + 10);
		records.push({
			platform: table.readUInt16BE(o),
			encoding: table.readUInt16BE(o + 2),
			language: table.readUInt16BE(o + 4),
			id: table.readUInt16BE(o + 6),
			bytes: table.subarray(off, off + len),
		});
	}
	return records;
}

export function writeNames(records: NameRecord[]): Buffer {
	const sorted = [...records].sort(
		(a, b) => a.platform - b.platform || a.encoding - b.encoding || a.language - b.language || a.id - b.id,
	);
	const header = Buffer.alloc(6 + sorted.length * 12);
	header.writeUInt16BE(0, 0);
	header.writeUInt16BE(sorted.length, 2);
	header.writeUInt16BE(header.length, 4);
	let off = 0;
	sorted.forEach((r, i) => {
		const o = 6 + i * 12;
		header.writeUInt16BE(r.platform, o);
		header.writeUInt16BE(r.encoding, o + 2);
		header.writeUInt16BE(r.language, o + 4);
		header.writeUInt16BE(r.id, o + 6);
		header.writeUInt16BE(r.bytes.length, o + 8);
		header.writeUInt16BE(off, o + 10);
		off += r.bytes.length;
	});
	return Buffer.concat([header, ...sorted.map((r) => r.bytes)]);
}

/** A Windows / Unicode BMP / en-US name record (UTF-16BE). */
export function winName(id: number, text: string): NameRecord {
	return { platform: 3, encoding: 1, language: 0x409, id, bytes: Buffer.from(text, "utf16le").swap16() };
}

export function nameText(r: NameRecord): string {
	return r.platform === 1 ? r.bytes.toString("latin1") : Buffer.from(r.bytes).swap16().toString("utf16le");
}

/** Unicode code point → glyph id, from the best Unicode cmap subtable (format 12 or 4). */
export function readCmap(table: Buffer): Map<number, number> {
	const count = table.readUInt16BE(2);
	let fmt4 = -1;
	for (let i = 0; i < count; i++) {
		const o = 4 + i * 8;
		const platform = table.readUInt16BE(o);
		const encoding = table.readUInt16BE(o + 2);
		const offset = table.readUInt32BE(o + 4);
		const format = table.readUInt16BE(offset);
		const unicode = platform === 0 || (platform === 3 && (encoding === 1 || encoding === 10));
		if (unicode && format === 12) return cmap12(table, offset);
		if (unicode && format === 4 && fmt4 < 0) fmt4 = offset;
	}
	if (fmt4 < 0) throw new Error("Font has no Unicode cmap subtable (format 4 or 12)");
	return cmap4(table, fmt4);
}

function cmap4(t: Buffer, o: number): Map<number, number> {
	const segX2 = t.readUInt16BE(o + 6);
	const ends = o + 14;
	const starts = ends + segX2 + 2;
	const deltas = starts + segX2;
	const ranges = deltas + segX2;
	const map = new Map<number, number>();
	for (let i = 0; i < segX2; i += 2) {
		const end = t.readUInt16BE(ends + i);
		const start = t.readUInt16BE(starts + i);
		const delta = t.readInt16BE(deltas + i);
		const rangeOffset = t.readUInt16BE(ranges + i);
		for (let c = start; c <= end && c !== 0xffff; c++) {
			let g: number;
			if (rangeOffset === 0) g = (c + delta) & 0xffff;
			else {
				g = t.readUInt16BE(ranges + i + rangeOffset + 2 * (c - start));
				if (g !== 0) g = (g + delta) & 0xffff;
			}
			if (g !== 0) map.set(c, g);
		}
	}
	return map;
}

function cmap12(t: Buffer, o: number): Map<number, number> {
	const groups = t.readUInt32BE(o + 12);
	const map = new Map<number, number>();
	for (let i = 0; i < groups; i++) {
		const p = o + 16 + i * 12;
		const start = t.readUInt32BE(p);
		const end = t.readUInt32BE(p + 4);
		const glyph = t.readUInt32BE(p + 8);
		for (let c = start; c <= end; c++) map.set(c, glyph + c - start);
	}
	return map;
}

/** Advance width of a code point's glyph in em units. */
export function advanceEm(font: Sfnt, codePoint: number): number {
	const table = (tag: string) => {
		const t = font.tables.get(tag);
		if (!t) throw new Error(`Font has no ${tag} table`);
		return t;
	};
	const gid = readCmap(table("cmap")).get(codePoint);
	if (gid === undefined) throw new Error(`Font has no glyph for U+${codePoint.toString(16).toUpperCase()}`);
	const metrics = table("hhea").readUInt16BE(34);
	const advance = table("hmtx").readUInt16BE(4 * Math.min(gid, metrics - 1));
	return advance / table("head").readUInt16BE(18);
}
```

```ts
// Builds src/font-data.ts: subsets of Monaspace Neon v1.400, pinned to static weights,
// renamed "ContribNeon Mono" (the OFL reserves the name "Monaspace" for unmodified
// fonts), with the original copyright and license kept in the name table.
// Run: npm run build:font
import { createHash } from "node:crypto";
import { mkdir, readFile, writeFile } from "node:fs/promises";
import { dirname } from "node:path";
import subsetFont from "subset-font";
import wawoff2 from "wawoff2";
import {
	advanceEm,
	nameText,
	readCmap,
	readNames,
	readSfnt,
	winName,
	writeNames,
	writeSfnt,
} from "./sfnt.ts";

const SOURCE_URL =
	"https://raw.githubusercontent.com/githubnext/monaspace/v1.400/fonts/Web%20Fonts/Variable%20Web%20Fonts/Monaspace%20Neon/Monaspace%20Neon%20Var.woff2";
const SOURCE_SHA256 = "6569968f448ae856ab5b57dff1f13b109b220ca8e3f664169e135fcb5c4f0721";
const CACHE = "node_modules/.cache/neon-kit/MonaspaceNeonVar-1.400.woff2";
const FAMILY = "ContribNeon Mono";
const OUT = "src/font-data.ts";

const range = (a: number, b: number) =>
	Array.from({ length: b - a + 1 }, (_, i) => String.fromCodePoint(a + i)).join("");

/** Characters each variant must contain; the build fails if any is missing. */
const REQUIRED = {
	hud: range(0x20, 0x7e),
	text: range(0x20, 0x7e) + range(0x410, 0x44f) + "Ёё",
};
/** Characters requested from the subsetter (extras are kept when the font has them). */
const WANTED = {
	hud: REQUIRED.hud,
	text: range(0x20, 0x7e) + range(0xa0, 0xff) + range(0x400, 0x45f) + "–—‘’“”…•",
};

const sha256 = (b: Buffer) => createHash("sha256").update(b).digest("hex");

async function source(): Promise<Buffer> {
	let buf: Buffer;
	try {
		buf = await readFile(CACHE);
	} catch {
		const res = await fetch(SOURCE_URL);
		if (!res.ok) throw new Error(`Download failed: HTTP ${res.status} for ${SOURCE_URL}`);
		buf = Buffer.from(await res.arrayBuffer());
		await mkdir(dirname(CACHE), { recursive: true });
		await writeFile(CACHE, buf);
	}
	const got = sha256(buf);
	if (got !== SOURCE_SHA256) throw new Error(`Source font checksum mismatch: ${got}`);
	return buf;
}

async function sourceNotices(src: Buffer): Promise<{ copyright: string; license: string }> {
	const raw = Buffer.from(await wawoff2.decompress(src));
	const names = readNames(readSfnt(raw).tables.get("name") as Buffer).filter((r) => r.platform === 3);
	const text = (id: number) => {
		const r = names.find((n) => n.id === id);
		if (!r) throw new Error(`Source font has no name ID ${id}`);
		return nameText(r);
	};
	return { copyright: text(7), license: text(13) };
}

function verify(sfnt: Buffer, required: string, label: string): void {
	const font = readSfnt(sfnt);
	if (font.tables.has("CFF ")) throw new Error(`${label}: unexpected CFF table`);
	const cmap = readCmap(font.tables.get("cmap") as Buffer);
	const missing = [...required].filter((ch) => !cmap.has(ch.codePointAt(0) as number));
	if (missing.length) throw new Error(`${label}: missing glyphs ${JSON.stringify(missing.join(""))}`);
	const adv = advanceEm(font, 0x41);
	if (adv !== 0.62) throw new Error(`${label}: advance of "A" is ${adv}em, expected 0.62em`);
	for (const r of readNames(font.tables.get("name") as Buffer)) {
		if (r.id >= 1 && r.id <= 6 && /monaspace/i.test(nameText(r)) && !/subset of/i.test(nameText(r))) {
			throw new Error(`${label}: name ID ${r.id} still uses the reserved name: ${nameText(r)}`);
		}
	}
}

async function build(
	src: Buffer,
	notices: { copyright: string; license: string },
	variant: "hud" | "text",
	weight: 400 | 700,
): Promise<string> {
	const style = weight === 700 ? "Bold" : "Regular";
	const subset = await subsetFont(src, WANTED[variant], {
		targetFormat: "sfnt",
		noLayoutClosure: true,
		variationAxes: { wght: weight, wdth: 100, slnt: 0 },
	});
	const font = readSfnt(Buffer.from(subset));
	font.tables.delete("STAT"); // axis names point at name records we drop
	font.tables.set(
		"name",
		writeNames([
			winName(0, notices.copyright),
			winName(1, FAMILY),
			winName(2, style),
			winName(3, `${FAMILY} ${style}; subset of Monaspace Neon 1.400`),
			winName(4, `${FAMILY} ${style}`),
			winName(5, "Version 1.400"),
			winName(6, `ContribNeonMono-${style}`),
			winName(13, notices.license),
			winName(14, "https://openfontlicense.org"),
		]),
	);
	const sfnt = writeSfnt(font);
	verify(sfnt, REQUIRED[variant], `${variant} ${weight}`);
	const woff2 = Buffer.from(await wawoff2.compress(sfnt));
	console.log(`${variant} ${weight}: ${woff2.length} bytes woff2`);
	return woff2.toString("base64");
}

const src = await source();
const notices = await sourceNotices(src);
const [hud400, text400, text700] = [
	await build(src, notices, "hud", 400),
	await build(src, notices, "text", 400),
	await build(src, notices, "text", 700),
];
await writeFile(
	OUT,
	"// Generated by scripts/build-font.ts from Monaspace Neon v1.400\n" +
		"// (c) 2023 GitHub, Inc., SIL Open Font License 1.1, renamed \"ContribNeon Mono\"\n" +
		"// per the OFL Reserved Font Name clause. See fonts/OFL.txt. Do not edit.\n" +
		`export const HUD_400 = "${hud400}";\n` +
		`export const TEXT_400 = "${text400}";\n` +
		`export const TEXT_700 = "${text700}";\n`,
);
console.log(`wrote ${OUT}`);
```

```ts
export function fontFace(variant: FontVariant, weights: FontWeight[] = [400]): string {

		return face(HUD_400, 400);
	}
	return weights.map((w) => face(w === 700 ? TEXT_700 : TEXT_400, w)).join("");
```

```ts
import type { Palette } from "./palette.ts";
import { r3 } from "./util.ts";

export interface Region {
	width: number;
	height: number;
}

/** One glitch tear: a horizontal band [y, y+h) shown at `at`% of the cycle, shifted by dx px. */
export interface Tear {
	y: number;
	h: number;
	at: number;
	dx: number;
}

export interface GlitchSpec {
	/** id of the element the tears copy (via <use>). */
	target: string;
	tears: Tear[];
	/** Horizontal extent of each tear's clip box. */
	band: { x: number; width: number };
	/** Seconds per cycle, and delay before the first cycle. */
	period: number;
	start: number;
	/** Fills the torn band so the shifted copy doesn't show the original underneath. */
	background: string;
}

export const TEAR_SECONDS = 0.126;

const BEAM_HEIGHT = 40;

export function scanlineDefs(p: Palette): string {
	const color = p.dark ? "#000000" : p.text;
	const opacity = p.dark ? 0.28 : 0.05;
	return `<pattern id="nk-sl" width="3" height="3" patternUnits="userSpaceOnUse"><rect width="3" height="1" fill="${color}" fill-opacity="${opacity}"/></pattern>`;
}

export const scanlines = (r: Region): string =>
	`<rect width="${r3(r.width)}" height="${r3(r.height)}" fill="url(#nk-sl)" pointer-events="none"/>`;

export function beamDefs(p: Palette): string {
	const mid = p.dark ? 0.09 : 0.06;
	return `<linearGradient id="nk-bm" x1="0" y1="0" x2="0" y2="1"><stop offset="0" stop-color="${p.accent}" stop-opacity="0"/><stop offset=".5" stop-color="${p.accent}" stop-opacity="${mid}"/><stop offset="1" stop-color="${p.accent}" stop-opacity="0"/></linearGradient>`;
}

export const beam = (r: Region): string =>
	`<rect class="nk-bm" width="${r3(r.width)}" height="${BEAM_HEIGHT}" fill="url(#nk-bm)" pointer-events="none"/>`;

export function beamCss(r: Region, o: { period: number; delay: number }): string {
	return (
		`.nk-bm{opacity:0;animation:nk-bm ${o.period}s ${r3(o.delay)}s linear infinite}` +
		`@keyframes nk-bm{0%{opacity:1;transform:translateY(-${BEAM_HEIGHT}px)}100%{opacity:1;transform:translateY(${r3(r.height)}px)}}`
	);
}

export function tintDefs(p: Palette, r: Region): string {
	const region = `filterUnits="userSpaceOnUse" x="0" y="0" width="${r3(r.width)}" height="${r3(r.height)}"`;
	const tint = (id: string, color: string) =>
		`<filter id="${id}" ${region}><feFlood flood-color="${color}"/><feComposite in2="SourceGraphic" operator="in"/></filter>`;
	return tint("nk-ta", p.glitchA) + tint("nk-tb", p.glitchB);
}

/** Clipped copies of `target`, torn sideways with a red/cyan channel split, a few times per cycle. */
export function glitchLayer(g: GlitchSpec): { defs: string; css: string; svg: string } {
	const dur = (TEAR_SECONDS / g.period) * 100;
	let defs = "";
	let css = "";
	let svg = "";
	g.tears.forEach((t, i) => {
		const box = `x="${r3(g.band.x)}" y="${r3(t.y)}" width="${r3(g.band.width)}" height="${r3(t.h)}"`;
		defs += `<clipPath id="nk-k${i}"><rect ${box}/></clipPath>`;
		const at = (f: number) => r3(t.at + dur * f);
		css +=
			`.nk-gk${i}{opacity:0;animation:nk-gk${i} ${g.period}s ${r3(g.start)}s steps(1,end) infinite}` +
			`@keyframes nk-gk${i}{0%,${r3(t.at)}%{opacity:0;transform:none}` +
			`${at(0.056)}%{opacity:1;transform:translateX(${r3(t.dx)}px)}` +
			`${at(0.389)}%{opacity:1;transform:translateX(${r3(-t.dx / 2)}px)}` +
			`${at(0.722)}%{opacity:1;transform:translateX(${r3(t.dx / 3)}px)}` +
			`${at(1)}%,100%{opacity:0;transform:none}}`;
		svg +=
			`<g clip-path="url(#nk-k${i})"><g class="nk-gk${i}">` +
			`<rect ${box} fill="${g.background}"/>` +
			`<use href="#${g.target}" filter="url(#nk-ta)" x="-2" opacity=".85"/>` +
			`<use href="#${g.target}" filter="url(#nk-tb)" x="2" opacity=".85"/>` +
			`<use href="#${g.target}"/></g></g>`;
	});
	return { defs, css, svg };
}

/** CRT power-on flicker for the card body, and a fade-in for the brackets. */
export function bootCss(seconds: number): string {
	const s = r3(seconds);
	return (
		`.nk-boot{animation:nk-boot ${s}s ease-out both}` +
		"@keyframes nk-boot{0%{opacity:0}35%{opacity:1}50%{opacity:.15}65%{opacity:1}80%{opacity:.55}100%{opacity:1}}" +
		`.nk-brk{animation:nk-brk ${s}s ease-out both}` +
		"@keyframes nk-brk{0%{opacity:0}100%{opacity:1}}"
	);
}

export const CURSOR_CSS = ".nk-cur{animation:nk-blink 1.1s steps(1,end) infinite}@keyframes nk-blink{50%{opacity:0}}";

export const REDUCED_MOTION_CSS = "@media (prefers-reduced-motion:reduce){*{animation:none!important}}";
```

```ts
import { brackets, panel } from "./frame.ts";
import { hudTitle } from "./hud.ts";
import { PALETTE_KEYS, type Palette } from "./palette.ts";
import { esc, r3, seeded } from "./util.ts";

export interface CardOptions {
	/** Content box size in px; the frame adds padding (and a title row) around it. */
	width: number;
	height: number;
	palette: Palette;
	/** Picks this card's glitch tear position, shift and timing. */
	seed: string;
	/** Accessible description (aria-label and <title>). */
	label: string;
	/** Optional `// TITLE` header with a blinking cursor. */
	title?: string;
	/** Embedded font. Default: the "hud" variant when a title is set, otherwise none. */
	font?: { variant: FontVariant; weights?: FontWeight[] } | false;
	glitch?: boolean;
	beam?: boolean;
	boot?: boolean;
	scanlines?: boolean;
}

export const CARD = { pad: 16, titleRow: 22, bootSeconds: 0.5, beamPeriod: 6, glitchPeriod: 10 } as const;

/** One seeded tear inside the content area. */
export function cardTears(seed: string, area: { y: number; height: number }): Tear[] {
	const rand = seeded(`glitch:${seed}`);
	const h = r3(Math.min(area.height, 6 + rand() * 10));
	// floor (not round) so the tear never extends past the content's bottom edge
	const y = r3(area.y + Math.floor(rand() * (area.height - h) * 1000) / 1000);
	const at = r3(5 + rand() * 80);
	const dx = r3((rand() < 0.5 ? -1 : 1) * (3 + rand() * 3));
	return [{ y, h, at, dx }];
}

function validate(o: CardOptions, content: string): void {
	if (!(Number.isFinite(o.width) && o.width > 0)) throw new Error(`card: width must be a positive number, got ${o.width}`);
	if (!(Number.isFinite(o.height) && o.height > 0)) throw new Error(`card: height must be a positive number, got ${o.height}`);
	if (!content.trim()) throw new Error("card: content is empty");
	const missing = PALETTE_KEYS.filter((k) => o.palette[k] === undefined);
	if (missing.length) throw new Error(`card: palette is missing ${missing.join(", ")}`);
}

/** Wraps `content` (SVG markup drawn from 0,0) in the animated neon frame; returns a complete <svg>. */
export function card(o: CardOptions, content: string): string {
	validate(o, content);
	const p = o.palette;
	const { pad, titleRow } = CARD;
	const top = pad + (o.title ? titleRow : 0);
	const width = r3(o.width + 2 * pad);
	const height = r3(top + o.height + pad);
	const region = { width, height };

	const font = o.font === undefined ? (o.title ? { variant: "hud" as const } : false) : o.font;
	const glitch =
		o.glitch === false
			? { defs: "", css: "", svg: "" }
			: glitchLayer({
					target: "nk-content",
					tears: cardTears(o.seed, { y: top, height: o.height }),
					band: { x: pad - 8, width: o.width + 16 },
					period: CARD.glitchPeriod,
					start: CARD.bootSeconds,
					background: p.background,
				});
	const label = esc(o.label);

	const css =
		(font ? fontFace(font.variant, font.weights) : "") +
		(o.boot === false ? "" : bootCss(CARD.bootSeconds)) +
		(o.beam === false ? "" : beamCss(region, { period: CARD.beamPeriod, delay: CARD.bootSeconds })) +
		(o.title ? CURSOR_CSS : "") +
		glitch.css +
		REDUCED_MOTION_CSS;
	const defs =
		(o.scanlines === false ? "" : scanlineDefs(p)) +
		(o.beam === false ? "" : beamDefs(p)) +
		(o.glitch === false ? "" : tintDefs(p, region)) +
		glitch.defs;

	return (
		`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 ${width} ${height}" width="${width}" height="${height}" role="img" aria-label="${label}">` +
		`<title>${label}</title>` +
		`<style>${css}</style>` +
		(defs ? `<defs>${defs}</defs>` : "") +
		`<g class="nk-boot">` +
		panel(width, height, p) +
		(o.title ? hudTitle(o.title, pad, pad + 10, p) : "") +
		`<g id="nk-content" transform="translate(${pad} ${r3(top)})">${content}</g>` +
		`</g>` +
		glitch.svg +
		(o.scanlines === false ? "" : scanlines(region)) +
		(o.beam === false ? "" : beam(region)) +
		`<g class="nk-brk">${brackets(width, height, p)}</g>` +
		`</svg>`
	);
}
```

```ts
import {
	beamCss,
	beamDefs,
	CURSOR_CSS,
	glitchLayer as kitGlitch,
	type Palette,
	REDUCED_MOTION_CSS,
	r3,
	scanlineDefs,

	type Tear,
	tintDefs,

import type { Grid } from "./grid.ts";

/** Seconds. Boot sweep runs once; everything else loops afterwards. */
export const TIMING = { colDelay: 0.022, rowDelay: 0.012, cellBoot: 0.4, glowIn: 0.9, scanPeriod: 6, glitchPeriod: 7 };

export const bootEnd = (cols: number) => cols * TIMING.colDelay + 6 * TIMING.rowDelay;

/** Per-level glow: blur radius, pulse opacity range, pulse period. Index = level. */
const GLOW = [
	null,
	{ blur: 2, lo: 0.55, hi: 0.85, period: 4 },
	{ blur: 2.6, lo: 0.65, hi: 0.95, period: 3.2 },
	{ blur: 3.2, lo: 0.75, hi: 1, period: 2.4 },
	{ blur: 4, lo: 0.85, hi: 1, period: 1.6 },
] as const;

/** Glow reads weaker on light backgrounds; scale it down to "lit ink". */
const glowScale = (p: Palette) => (p.dark ? 1 : 0.7);

export function filterDefs(g: Grid, p: Palette): string {
	const region = `filterUnits="userSpaceOnUse" x="0" y="0" width="${g.width}" height="${g.height}"`;
	const glows = [1, 2, 3, 4]
		.map((l) => {
			const { blur } = GLOW[l] as NonNullable<(typeof GLOW)[number]>;
			return `<filter id="g${l}" ${region}><feGaussianBlur stdDeviation="${blur}" result="b"/><feMerge><feMergeNode in="b"/><feMergeNode in="b"/><feMergeNode in="b"/></feMerge></filter>`;
		})
		.join("");
	return glows + tintDefs(p, g) + scanlineDefs(p) + beamDefs(p);
}

export function baseCss(g: Grid, p: Palette): string {
	const end = bootEnd(g.cols);
	const s = glowScale(p);
	const levels = [1, 2, 3, 4]
		.map((l) => {
			const { lo, hi, period } = GLOW[l] as NonNullable<(typeof GLOW)[number]>;
			const [a, b] = [r3(lo * s), r3(hi * s)];
			const ignite = r3(Math.min(1, hi * s * 1.25));
			return (
				`.p${l}{opacity:${a};animation:i${l} ${TIMING.glowIn}s ${r3(end)}s ease-out both,p${l} ${period}s ${r3(end + TIMING.glowIn)}s ease-in-out infinite}` +
				`@keyframes i${l}{0%{opacity:0}55%{opacity:${ignite}}100%{opacity:${a}}}` +
				`@keyframes p${l}{0%,100%{opacity:${a}}50%{opacity:${b}}}`
			);
		})
		.join("");
	const core = GLOW[4] as NonNullable<(typeof GLOW)[4]>;
	return [
		`.c{animation:boot ${TIMING.cellBoot}s ease-out both}`,
		"@keyframes boot{0%{opacity:0}35%{opacity:1}50%{opacity:.15}65%{opacity:1}80%{opacity:.55}100%{opacity:1}}",
		levels,
		`.k{opacity:.55;animation:i4 ${TIMING.glowIn}s ${r3(end)}s ease-out both,k ${core.period}s ${r3(end + TIMING.glowIn)}s ease-in-out infinite}`,
		"@keyframes k{0%,100%{opacity:.55}50%{opacity:.95}}",
		`.hd{opacity:0;animation:hd ${r3(end)}s linear both}`,
		`@keyframes hd{0%{opacity:1;transform:translateX(0)}90%{opacity:1}100%{opacity:0;transform:translateX(${g.gridWidth}px)}}`,
		beamCss(g, { period: TIMING.scanPeriod, delay: end }),
		CURSOR_CSS,
		`.hud{animation:flick ${TIMING.glitchPeriod}s ${r3(end)}s steps(1,end) infinite}`,
		"@keyframes flick{0%,100%{opacity:1}61%{opacity:.35}62%{opacity:1}63%{opacity:.6}64%{opacity:1}}",
		REDUCED_MOTION_CSS,
	].join("");
}

/** 3 horizontal tears at seeded grid rows/times, each showing a red/cyan channel split. */
export function glitchTears(g: Grid, user: string): Tear[] {
	const rand = seeded(`glitch:${user}`);
	const step = g.cell + g.gap;
	return [0, 1, 2].map((i) => {
		const rows = rand() < 0.5 ? 1 : 2;
		const row = Math.floor(rand() * (8 - rows));
		return {
			y: g.gridTop + row * step - g.gap / 2,
			h: rows * step,
			// spread the three tears across the cycle so they don't stack
			at: r3(10 + i * 27 + rand() * 15),
			dx: r3((rand() < 0.5 ? -1 : 1) * (3 + rand() * 6)),
		};
	});
}

export function glitchLayer(g: Grid, p: Palette, user: string) {
	return kitGlitch({
		target: "cells",
		tears: glitchTears(g, user),
		band: { x: g.gridLeft - 12, width: g.gridWidth + 24 },
		period: TIMING.glitchPeriod,
		start: r3(bootEnd(g.cols) + TIMING.glowIn),
		background: p.background,
	});
}
```
